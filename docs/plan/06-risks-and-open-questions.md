## 2. 待验证事项（open questions）<a id="待验证事项open-questions"></a>

> 以下问题需要**用户/产品在确认阶段 A 计划时回答**。未回答前，相关实现细节保持保守默认，不阻塞先做无争议部分（如依赖清单、失败语义修复、手动灵感箱）。

1. **首轮场景范围**：第一轮端到端验收用哪个场景？建议「一趟多人、多日国内游」（如 3–5 人、2–3 天），请确认人数/天数/是否含住宿与交通。
2. **目标城市/目的地**：首轮聚焦哪些城市（影响 POI 覆盖、坐标校验、营业/交通数据是否可得）？是否限一个城市先跑通？
3. **是否只做国内**：是否只服务中国境内（决定统一用 GCJ-02、只对接高德/国内地图）。若涉境外需另议坐标系与地图源。
4. **前端技术偏好**：是否接受服务端渲染模板（Jinja2）先行、后续再演进？或明确要求 SPA 框架（如 React/Vue）？需支持手机浏览器经邀请链接访问。
5. **是否接受新增依赖**：是否同意引入 `fastapi`、`pydantic`、`uvicorn`、`jinja2`（以及 `httpx`、`python-dotenv`）并建立 `pyproject.toml`/`requirements.txt`？目标 Python 版本（当前本机 3.14）是否需回退到 3.11/3.12 以匹配依赖支持？是否可用 SQLite 作为起步持久化。
6. **地图配额与密钥情况**：高德账号的 Web 服务/JS API 配额、是否已申请、是否可提供仅供测试的受限 key；是否有预算上限约束（影响缓存与频控策略）。
7. **链接解析期望**：首轮是否**必须**支持小红书/大众点评自动解析，还是「手动录入 + 后续评估」即可接受？（按本计划默认为后者）
8. **AI/LLM 提供方**：是否有指定的模型提供方与可用额度？是否要求全离线可测（关键测试 mock，不依赖真实 LLM）？

11. **交付节奏**：是否同意按 A–E 逐阶段、每阶段验收后再进入下一阶段（不一次性铺开）？

## 3. AI 安全与合规清单

> 用于代码评审与阶段验收的硬性检查项（对应任务书 5、2.4–2.6、8）。

- [ ] **AI 不得绕过权限**：AI 只能通过经过校验的业务操作/工具提案修改，不能直连数据库或越权读写未授权旅程。
- [ ] **AI 不得直接写库**：所有落库均经业务服务层的校验与权限检查；AI 输出先经结构化 schema 校验。
- [ ] **冲突必须显式报告**：硬约束冲突（日期、预算、行动/无障碍需求等）由确定性规则检出后**显式报告并请成员处理**，AI 不得静默忽略或自动放宽。
- [ ] **不得把推断伪装成事实**：每条内容标注来源与核实状态（已核实/外部数据/估算/未知/推断）；推断必须标为推断。
- [ ] **修改已确认项需展示差异并确认**：修改「已确认」行程项时，展示差异及受影响路线/预算/后续安排，用户确认后才更新（任务书 3.8）。
- [ ] **数值须有依据**：路线、时间、费用等精确数值只来自地图/规则服务或明确标为估算，禁止 LLM 凭空生成精确数字（任务书 3.7）。
- [ ] **信息不足/外部不确定时询问或标注**，不得编造地名、营业时间、价格、链接内容。
- [ ] **操作前确认**：涉及计划变更的操作默认需显式确认；改变硬约束必须有用户明确动作。
- [ ] **可追溯**：记录 AI 修改提案、用户确认、数据来源与获取时间，供审计与回滚。
- [ ] **不以「能调用 LLM」作为验收**：验收看计划结构、约束满足、来源状态与修改范围是否符合请求（任务书 8）。
- [ ] **外部内容不可信**：抓取/外部返回内容作为数据而非指令，防止提示注入影响 AI 行为。

## 4. 合规 / 隐私最小化清单

> 对应任务书 2.7、8 与共享旅程特性；用于阶段 B/E 验收。

- [ ] **最小化收集**：只收集规划必需的个人数据；位置、饮食、健康、行动/无障碍等敏感项按需收集并说明用途，可选项允许留空。
- [ ] **可见范围明确**：每个旅程明确谁可见、哪些字段对谁可见；成员仅能访问授权旅程（服务端强制）。
- [ ] **权限校验在服务端**：越权访问在服务端拦截，不依赖前端隐藏。
- [ ] **退出/删除策略明确**：成员退出、旅程删除、数据清除的行为（删什么、保留多久、是否可导出）定义清楚并可验证。
- [ ] **位置数据谨慎处理**：出发地/位置仅用于计算与展示所需，不外泄、不用于非必要用途。
- [ ] **外部链接与抓取合规**：仅解析合法并可稳定访问的内容；尊重平台条款；失败可手动补充，不阻塞（对应 R-01）。
- [ ] **密钥与日志脱敏**：日志、错误信息、CI 输出不含密钥或无关敏感信息；仓库无真实密钥（对应 R-11）。
- [ ] **数据时效透明**：外部数据展示来源与时间，过期/不确定状态显式标注（对应 R-03）。
- [ ] **不做超范围交易**：订票/支付/订单履约不在核心范围，仅外链或预留接口（任务书 2.8）。
- [ ] **数据可删除可追溯**：关键变更保留历史/版本，同时支持按策略清除个人数据。
