# FairMeet

> 多人公平会面点推荐引擎 —— 解决"我们在哪见？"的群体决策问题。

🚧 **开发中**（Phase 0：最小可用内核）

## 它做什么

输入多个参与者的出发位置，计算对所有人**公平**的会面中心点，在中心点周边搜索候选场所（咖啡厅/餐厅），按多因子加权评分排序，并生成标注了所有参与者与推荐场所的交互地图。

```
地址列表 → 地理编码 → 公平中心计算 → POI 搜索 → 多因子评分 → 地图展示
```

## 路线图

| 阶段 | 内容 | 状态 |
|------|------|------|
| Phase 0 | 最小内核：完整推荐管线 + 测试 | 🚧 进行中 |
| Phase 1 | 公平性升级：用真实通勤时间（等时圈）替代地理中点，方差最小化 | ⬜ |
| Phase 2 | 多轮对话 Agent：对话式调整推荐（"换一个离地铁近的"） | ⬜ |
| Phase 3 | 工程质量：Docker、CI、压测与性能优化 | ⬜ |

## 技术栈

Python 3.11+ · FastAPI · httpx · pytest · respx · 高德地图 API
